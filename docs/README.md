# ZengLauncher

ZengLauncher is a desktop launcher for installing and managing Minecraft versions and isolated instances. It supports Windows, macOS, and Linux.

## Build

Use the CMake presets in `CMakePresets.json`. Follow the upstream build requirements in [`CONTRIBUTING.md`](CONTRIBUTING.md), then configure and build the preset for your platform.
