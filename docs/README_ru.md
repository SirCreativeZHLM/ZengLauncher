# ZengLauncher

ZengLauncher — настольный лаунчер для установки и управления версиями Minecraft и изолированными игровыми экземплярами. Поддерживаются Windows, macOS и Linux.

## Сборка

Используйте пресеты CMake из `CMakePresets.json` и инструкции по сборке в [`docs/CONTRIBUTING.md`](CONTRIBUTING.md).

## Исходный код и лицензия

ZengLauncher основан на Freesm Launcher и Prism Launcher. Исходный код, лицензии и уведомления об авторстве сохранены. См. [`LICENSE`](../LICENSE) и заголовки исходных файлов.
